## Лабораторні роботи з дисципліни "Алгоритмізація та програмування"
## Виконала: Руденко Єкатерина Олексіївна(ІР-13)
## Лабораторна робота № (варіант8 8)

Для виконання першого завдання створила два варіанти виконання
Перший варіант реалізує систему складу, де використовується структура даних стек (LIFO) для зберігання коробок. Клас Warehouse містить методи для додавання (push), видалення (pop), перегляду верхнього елементу (peek), перевірки порожнечі (is_empty) та отримання кількості коробок на складі (size). Клас також підтримує ітерацію. Програма додає коробки на склад, а потім по черзі їх видаляє, виводячи інформацію про кожну коробку під час процесу видалення та поточний стан складу.
У другому варіанті ористувач може взаємодіяти через командний інтерфейс, вводячи команди для додавання нових коробок, видалення верхньої коробки або завершення програми. Якщо склад порожній і користувач спробує видалити коробку, програма викидає помилку, яку обробляє блок except, виводячи повідомлення про помилку.

Друге завдання реалізується система замовлень для ресторану. Клас Order представляє окреме замовлення з описом, часом виконання та статусом (очікує, в процесі, виконано). Клас RestaurantOrders управляє чергою замовлень, обробляючи їх по черзі, оновлюючи статуси замовлень, зберігаючи виконані замовлення та відстежуючи витрачений час. Користувач може взаємодіяти з програмою через командний інтерфейс, використовуючи команди для додавання замовлень, обробки замовлень за часом, перегляду меню та статусу замовлень.
